Simulador e Consolidador de Declaração de IRPF

Projeto Prático - Santander Bootcamp / Excel (DIO)

Este projeto apresenta uma planilha automatizada criada no Microsoft Excel para organizar e consolidar dados do Imposto de Renda. 
A ferramenta foi desenvolvida para estruturar e validar as informações fiscais de forma prática e profissional.
O que a planilha faz:
Cadastro Completo: Organiza os dados pessoais obrigatórios (Nome, CPF, Título de Eleitor) e usa perguntas de controle (como "Houve alterações?") para validar as informações.
Saldos Bancários: Soma e consolida os valores que você tem em diferentes bancos (como Banco do Brasil, Caixa e Bonsucesso) para preencher a ficha de Bens e Direitos.
Tabela de Bancos: Possui uma lista com mais de 50 bancos oficiais para ajudar a selecionar os códigos corretos de forma automática.
Controle de Receitas: Registra as entradas de dinheiro mês a mês (como recebimentos de CNPJ) para facilitar o controle dos rendimentos.
